# PWA Icons

This directory should contain the following icon files for the PWA:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

These icons are referenced in the manifest.json file and are used for:
- Home screen icons on mobile devices
- App installation prompts
- Splash screens
- Task switchers

Please create these icons with your branding and place them in this directory.
